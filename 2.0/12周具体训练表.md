# 12周具体训练表

下面我直接把前面那套系统落成两套可执行的12周计划：

**A版：3日版**——适合工作日时间有限，但仍然以篮球运动员训练逻辑进行。

**B版：4/5日版**——4天是完整主计划，第5天作为篮球专项日/恢复性技术日，根据状态决定是否加入。

这两套并不是两套完全不同的训练体系，而是同一个12周周期的不同训练频率版本。这样以后你从3天增加到4/5天，不需要重新开始。

你原来的框架已经确定了"爆发/速度优先、力量训练之间保证恢复、篮球技巧可独立或接在力量后、防伤训练不能跳过"的基本原则。下面完全沿用这个逻辑，并把它扩展到落地、减速、单腿和篮球专项。

## 二、先规定所有训练日的固定结构

无论3日还是4/5日，都使用这个顺序：

1. **热身** — 8–10分钟
2. **Level 2 防伤** — 约5分钟。你的原方案中已经明确训练前Level 2是固定环节，根据当天训练类型选择2–3个动作。
3. **速度/爆发** — 10–15分钟
4. **主力量** — 20–30分钟
5. **辅助/单腿/防伤** — 10–20分钟
6. **核心** — 5–10分钟
7. **篮球/体能** — 根据当天安排

## 三、训练强度统一使用RPE

不要一开始就给你死规定某个公斤数。因为不知道你当前深蹲、Trap Bar、RDL等准确水平，所以用RPE更适合。

| RPE | 感觉 |
|-----|------|
| 5 | 很轻，明显可以继续 |
| 6 | 轻中等，还能做4次左右 |
| 7 | 还能做约3次 |
| 8 | 还能做约2次 |
| 9 | 还能做约1次 |
| 10 | 力竭 |

12周绝大部分训练不需要RPE 9–10。

## 二十一、为什么这样拆？

比如3日版：
- D1 力量 + 爆发
- D2 上肢 + 篮球
- D3 速度 + 变向 + 篮球

4日版变成：
- D1 下肢A
- D2 上肢 + 技术
- D3 Speed / Decel
- D4 下肢B + Conditioning

于是：**每个训练日质量更高**。

这比"每天都练一点所有东西"更符合你想要的运动员模式。

## 二十二、一个动作什么时候换？

不要因为"动作做腻了"就换。建立这个规则：

**保留动作**

如果：动作稳定、RPE正常、没有疼痛、仍然有进步 → 继续。

**升级动作**

例如：CMJ → Box Jump → Depth Jump

**降级动作**

如果：疲劳、技术下降、疼痛增加

例如：Depth Jump → Box Jump → CMJ

**替换动作**

如果动作模式已经充分覆盖或设备条件变化。

## 二十三、你的动作库选择公式

以后可以直接这样理解：

```
当天训练目标
↓
能力短板
↓
周期阶段
↓
动作等级
↓
疼痛限制
↓
恢复状态
↓

```

例如今天：**Phase 2 + Lower A + 单腿能力差 + 疲劳正常**

那么：
- **Plyo** → Box Jump
- **Main** → Trap Bar
- **Single-leg** → Bulgarian Split Squat
- **Posterior** → RDL
- **Prehab** → Band Walk + Knee Control
- **Core** → Pallof

不需要再去动作库随机找。

## 二十五、疼痛状态如何修改这12周计划

采用一个非常简单的规则。

> 🟢 **正常**
>
> 疼痛：0–2/10 且训练后/第二天没有明显恶化。
>
> → 照计划

> 🟡 **注意**
>
> 疼痛比平常明显提高，或者第二天恢复不好。
>
> → 力量训练量 -20%、Plyo -50%、取消高强度COD、篮球减少对抗

> 🔴 **暂停高冲击**
>
> 出现尖锐疼痛、肿胀、卡顿、明显不稳定、越来越疼。
>
> → 不做高冲击跳跃、冲刺和变向，并进行专业评估

你原指南本身也规定：以无痛范围训练，出现刺痛立即停止；持续4–6周没有改善则建议进行运动医学/康复评估。

## 二十九、最终建议你实际采用哪个版本？

按照你的目标"半职业甚至职业方式训练"，我的建议是：

**W5开始**：身体反应稳定以后，切4日版。

**第5天**：不是强制。只在恢复良好 + 膝部稳定 + 篮球技术需要时加入。

最终形成：

- **3日** → 基础运动员模式
- **4日** → 半职业训练模式
- **4+1日** → 半职业 + 篮球专项强化
