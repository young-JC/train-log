二十、给动作增加一个真正有用的“等级体系”

不要仅仅用：

⭐ / ⭐⭐ / ⭐⭐⭐

建议改成：

L1 基础

能够：

正确完成动作

L2 运动员基础

能够：

在负重、速度或者单腿情况下稳定完成

L3 运动表现

能够：

在高速、爆发、复杂环境下完成

L4 篮球专项

能够：

在反应、对抗、疲劳条件下完成

例如：

深蹲

L1 高脚杯深蹲
↓
L2 六角杠深蹲
↓
L3 重负荷深蹲
↓
L4 深蹲 → 跳跃 → 冲刺

再比如：

侧向能力

L1 侧弓步
↓
L2 滑冰者跳（Skater Jump）
↓
L3 侧向跨跳（Lateral Bound）
↓
L4 侧向跨跳（Lateral Bound） → Sprint → 防守接近（Closeout）

这才是真正的“运动员进阶”。

## 二十三、动作库 2.1：中文名称 + 标准动作说明 + 视频入口

### 1. 使用规则

从这一版开始，动作名称统一采用：

> **中文名称（English Name）**

英文保留的目的只是方便你在 YouTube、Google、NSCA/训练资料等平台搜索；日常训练计划、打卡和数据库前端优先显示中文名称。

每个动作建议增加以下字段：

| 字段 | 用途 |
|---|---|
| 中文名称 | 训练计划、打卡页面主要显示 |
| 英文名称 | 搜索资料、视频和专业教材 |
| 动作描述 | 明确起始姿势、主要动作、结束姿势 |
| 关键要点 | 判断动作是否做对 |
| 常见错误 | 防止错误代偿 |
| 视频 | 查看实际动作演示 |
| 难度/L1-L4 | 控制进阶 |
| 能力标签 | 用于自动选动作 |
| RPE/RIR | 控制训练强度 |
| 进阶条件 | 什么时候升级 |
| 退阶条件 | 疲劳/疼痛时如何降低难度 |

### 2. 对复合训练动作的统一描述方式

对于“冲刺→急停→变向”“跳跃→落地→再次跳跃”这类复合动作，不建议只写一个动作名称。以后训练计划中统一写成：

**起始姿势 → 第一阶段 → 制动/稳定 → 第二阶段 → 完成标准**

例如：

**冲刺→急停→90°变向（Sprint → Stop → 90° Cut）**

1. 从准备姿势开始加速；
2. 达到规定距离后提前降低重心；
3. 通过多步减速吸收水平速度；
4. 支撑脚稳定后完成90°变向；
5. 重新加速；
6. 重点观察膝盖轨迹、躯干控制和变向后第一步。

### 3. 视频动作库建议

你的动作库最终不要只存一个 URL，而建议存：

`video_url`：固定教学视频  
`video_search_url`：备用搜索入口  
`video_source`：视频来源  
`video_checked_at`：最近人工检查日期

这样以后做 HTML 动作库时，可以直接显示：

**动作名称 → 动作说明 → 关键要点 → ▶ 查看视频 → 训练记录**

这也更适合你后面做“动作库 → 能力评估 → 12周周期 → 周计划 → 每日训练 → 打卡 → 自动调整”的系统化训练工具。

下一步建议

这套 2.0 动作库先不要直接拿来排每天训练。更合理的做法是再给每个动作增加 「组数 × 次数 × 休息 × RPE/RIR × 进阶条件 × 退阶条件 × 禁忌/疼痛规则」，然后把 100+ 个动作做成一个可以长期维护的数据库。

最终你的训练系统就可以变成：

动作库 2.0 → 能力评估 → 12周周期 → 周计划 → 每日训练 → 学习/训练打卡 → 疼痛记录 → 自动调整训练量。

这会比单纯的一张“每周训练表”更适合你想要的半职业/职业篮球训练模式。
