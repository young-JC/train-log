# 🏀 篮球运动员版动作库 2.0

## 一、先建立新的动作库体系

以后不再按照"胸、背、腿"这种健身分类，而按照篮球运动能力分类：

| 模块 | 核心目的 |
|---|---|
| A. Mobility 活动度 | 保证动作幅度 |
| B. Prehab 防伤 | 提高组织耐受 |
| C. Landing 落地 | 学会安全吸收力量 |
| D. Deceleration 减速 | 学会刹车 |
| E. Plyometric 弹跳 | 提高爆发 |
| F. Lower Strength 下肢力量 | 提高力量基础 |
| G. Single-leg 单腿力量 | 篮球专项力量 |
| H. Upper Strength 上肢力量 | 对抗、护球 |
| I. Core 核心 | 抗旋转/抗伸展 |
| J. Speed 速度 | 启动、加速 |
| K. Agility 敏捷 | 变向、反应 |
| L. Basketball 技术 | 运球/投篮/终结 |
| M. Conditioning 体能 | 比赛持续能力 |
| N. Recovery 恢复 | 降低疲劳积累 |
| O. Kinetic Chain 全身力量传递 | 下肢→核心→上肢力量链 |

这样以后增加动作也不会乱。

- 单腿侧向跳（Single-Leg Lateral Jump） → 停 ⭐⭐⭐

#### D3 高级

- 冲刺→180°转身（Sprint → 180° Turn）

### O. 全身力量传递（Kinetic Chain / Total-Body Power）

篮球不是"腿练腿、肩练肩"，而是：

```text
地面 → 脚 → 踝 → 膝 → 髋 → 核心 → 肩 → 手
```

这一模块专门训练**下肢→核心→上肢的力量传递**，是篮球对抗、起跳、传球和终结的底层能力。

#### O1 分腿姿上肢爆发（Split-Stance Upper Power）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press） | L2 | 分腿稳定、抗旋转、上下肢力量传递 |
| 分腿姿快速蹬伸单臂推举（Split-Stance Explosive Single-Arm Push Press） | L3 | 地面反作用力→髋→核心→肩→手的爆发链 |
| 分腿姿地雷管推举（Split-Stance Landmine Press） | L2 | 力量传递 + 肩胛稳定 |
| 半跪姿单臂地雷管推举（Half-Kneeling Landmine Press） | L2 | 髋稳定 + 核心抗旋转 + 肩推 |

**推荐做对侧负重**：左腿在前 → 右手持哑铃，产生旋转力矩迫使核心抗旋转。

#### O2 负重爆发（Loaded Explosive Movement）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 壶铃摆动（Kettlebell Swing） | L2 | 髋主导爆发、后链力量 |
| 哑铃高拉（Dumbbell High Pull） | L2–L3 | 快速伸髋、力量传递（无需 Catch） |
| 悬垂哑铃高翻（Hang Dumbbell Clean） | L3 | 快速伸髋 + RFD + 协调 |
| 哑铃高翻（Dumbbell Clean） | L3 | 全身负重爆发 |
| 单臂哑铃抓举（Single-Arm Dumbbell Snatch） | L3–L4 | 全身爆发最高阶 |
| 壶铃高翻（Kettlebell Clean） | L3 | 髋爆发 |
| 壶铃高翻推举（Kettlebell Clean & Press） | L3 | 全身力量链 |
| 壶铃单臂摆动（Single-Arm KB Swing） | L2–L3 | 髋爆发 + 抗旋转 |
| 哑铃火箭推（Dumbbell Thruster） | L2 | 蹲→伸髋伸膝→推举；低次数偏 Power，高次数偏 Conditioning |

**进阶链**：壶铃摆动 → 哑铃高拉 → 悬垂哑铃高翻 → 哑铃高翻 → 单臂哑铃抓举

#### O3 抗旋转复合（Anti-Rotation Complex）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 俯卧撑位交替哑铃划船（Renegade Row） | L2 | 划船 + 抗旋转核心 + 肩胛稳定 + 髋稳定 |

## 二十、给动作增加一个真正有用的"等级体系"

不要仅仅用：

⭐ / ⭐⭐ / ⭐⭐⭐

建议改成：

**L1 基础**

能够：

> 正确完成动作

**L2 运动员基础**

能够：

> 在负重、速度或者单腿情况下稳定完成

**L3 运动表现**

能够：

> 在高速、爆发、复杂环境下完成

**L4 篮球专项**

能够：

> 在反应、对抗、疲劳条件下完成

例如：

**深蹲**

```text
L1 高脚杯深蹲
↓
L2 六角杠深蹲
↓
L3 重负荷深蹲
↓
L4 深蹲 → 跳跃 → 冲刺
```

再比如：

**侧向能力**

```text
L1 侧弓步
↓
L2 滑冰者跳（Skater Jump）
↓
L3 侧向跨跳（Lateral Bound）
↓
L4 侧向跨跳（Lateral Bound） → Sprint → 防守接近（Closeout）
```

这才是真正的"运动员进阶"。

### 膝盖靠墙踝背屈

**标准动作描述：** 面向墙站立，脚尖距墙约5–10厘米；脚跟始终贴地，让膝盖向第二脚趾方向前移并轻触墙面，再回到起始位。左右腿分别测试/训练，避免足弓塌陷和膝盖内扣。


### 动态踝背屈

**标准动作描述：** 站立或半跪位，以脚跟不离地为前提，让膝盖反复向前越过脚尖，再回到中立位；动作连续但不弹震。


### 深蹲位踝背屈

**标准动作描述：** 进入舒适深蹲位，在脚跟贴地的情况下主动将膝盖向前移动，感受踝背屈；保持足弓和膝盖方向稳定。


### 小腿动态拉伸

**标准动作描述：** 一脚前、一脚后站立，在后脚跟保持接触地面的情况下反复屈伸踝关节；可缓慢前移身体增加活动幅度。


### 90/90 髋部转换（90/90 Hip Switch）

**标准动作描述：** 坐姿双腿弯曲约90°，双膝向一侧倒下，再通过髋关节旋转转换到另一侧；保持躯干尽量稳定。


### 90/90 髋部前倾（90/90 Forward Fold）

**标准动作描述：** 进入90/90坐姿，保持背部较长，从髋部向前倾，回到直立；不要通过弯腰塌背强行增加幅度。


### 世界最伟大拉伸（World's Greatest Stretch）

**标准动作描述：** 弓步位，前脚落地；同侧手臂向上旋转打开胸椎，再将肘部向前脚内侧靠近；左右交替。


### 内收肌后坐拉伸（Adductor Rock Back）

**标准动作描述：** 四点跪姿，一腿向侧方伸直，脚掌贴地；臀部向后坐至内侧大腿产生拉伸，再返回。


### 哥萨克深蹲（Cossack Squat）

**标准动作描述：** 双脚宽站，一侧屈膝下沉，另一侧腿伸直、脚尖朝上或保持自然；躯干保持控制，再推回中间换侧。


### 髋飞机（Hip Airplane）

**标准动作描述：** 单腿站立，另一腿向后伸；保持骨盆稳定，通过髋关节旋转让骨盆向外打开再回正，必要时扶墙完成。


### 墙滑（Wall Slide）

**标准动作描述：** 背部靠墙或面向墙站立，肘和手臂保持受控接触墙面，沿墙向上滑，再缓慢回落；避免耸肩和腰椎过度伸展。


### 胸椎旋转

**标准动作描述：** 四点跪姿，一手放于头后；保持骨盆稳定，通过胸椎旋转将肘部指向对侧地面，再向上打开至天花板方向，左右交替。避免用腰椎旋转代偿，动作范围以胸椎活动为准。


### 弹力带肩部绕环（Band Shoulder Dislocate）

**标准动作描述：** 站立，双手宽握弹力带置于体前；保持手臂基本伸直，将弹力带从体前经头顶绕到体后，再原路返回。握距以肩部无痛、动作可控为准，避免耸肩和腰部过伸。


### 弹力带侧走

**标准动作描述：** 弹力带置于膝上或脚踝，髋膝轻屈；向侧方迈步，保持骨盆水平和膝盖对准脚尖，连续侧向移动。


### 站姿膝控

**标准动作描述：** 单腿站立，缓慢屈髋屈膝，观察膝盖始终朝向第二脚趾；必要时降低动作幅度。


### 台阶下蹲（Step Down）

**标准动作描述：** 站在低台阶上，单腿支撑；另一脚缓慢向下探地，再由支撑腿推回起始位。全过程控制骨盆和膝盖。


### 西班牙深蹲（Spanish Squat）

**标准动作描述：** 用固定带/弹力带支撑膝后侧，身体向后坐并屈膝下蹲；保持躯干相对直立，再站起。以舒适范围和稳定性为先。


### 蚌式

**标准动作描述：** 侧卧、髋膝弯曲，双脚并拢；保持骨盆不向后翻，用上侧髋外旋打开膝盖，再缓慢闭合。


### 侧卧髋外展

**标准动作描述：** 侧卧，下侧腿可弯曲稳定，上侧腿伸直；保持脚尖朝前，用髋部抬高上侧腿，再控制下降。


### 弹力带髋外展

**标准动作描述：** 弹力带置于膝上或脚踝，站立或半蹲；将腿向侧方打开，骨盆保持稳定后回到起始位。


### 滑动腿弯举

**标准动作描述：** 仰卧，脚跟踩滑垫/毛巾；抬起臀部后屈伸膝，将脚跟拉向臀部，再控制伸直。


### 瑞士球腿弯举

**标准动作描述：** 仰卧，双脚放在瑞士球上；抬髋后屈膝把球拉近，再缓慢伸膝。


### 辅助北欧腘绳肌弯举（Assisted Nordic Hamstring Curl）

**标准动作描述：** 跪姿固定脚踝，身体从膝关节向前倾；用手或弹力带辅助控制下降，再回到起始位。重点是慢速离心。


### 短杠杆哥本哈根侧桥（Short-Lever Copenhagen）

**标准动作描述：** 侧桥姿势，将上侧膝盖放在凳面，支撑身体并保持骨盆抬高；另一腿悬空或自然放置。


### 长杠杆哥本哈根侧桥（Long-Lever Copenhagen）

**标准动作描述：** 侧桥姿势，将上侧小腿/脚踝放在凳面，保持身体成一直线；用内收肌和侧核心稳定骨盆。


### 双腿提踵

**标准动作描述：** 站立扶稳，脚掌前部着地；抬高脚跟至最大舒适范围，再缓慢下降。


### 单腿提踵

**标准动作描述：** 单腿站立扶稳，脚跟下降后主动踮起，保持脚踝轨迹稳定，不向内外塌。


### 屈膝提踵

**标准动作描述：** 膝盖保持轻度弯曲进行提踵，重点训练屈膝状态下的小腿/比目鱼肌。


### 单腿平衡

**标准动作描述：** 单脚站立，保持骨盆和足弓稳定；可逐渐加入闭眼、触地或轻微动态干扰。


### 踝弹跳（Pogo Jump）

**标准动作描述：** 膝盖保持轻微弯曲，以脚踝快速弹性完成连续小幅跳跃；落地安静、触地时间短，不追求高度。


### 快速下落定住（Snap Down）

**标准动作描述：** 站立后快速摆臂下落到运动准备位，髋膝踝同步屈曲并稳定定住；重点练习快速吸收力量。


### 深蹲式落地（Squat Landing）

**标准动作描述：** 从小跳落地，双脚同时着地，髋膝踝屈曲吸收冲击，膝盖对准脚尖，稳定后再站起。


### 下落落地（Drop Landing）

**标准动作描述：** 从低台阶走下或小幅跳下，双脚落地并主动屈髋屈膝吸收冲击；先练稳定，再逐渐提高高度。


### 落箱反应跳（Drop Jump）

**标准动作描述：** 从低箱下落，落地后尽快完成垂直起跳；强调落地位置、刚性和快速反应，不以高度替代动作质量。


### 反向动作纵跳（Countermovement Jump）

**标准动作描述：** 站立快速下蹲并立即向上起跳，利用下蹲反向动作产生弹性；双脚稳定落地。


### 深蹲跳（Squat Jump）

**标准动作描述：** 先停在固定深蹲位，再不借助明显反向下蹲直接向上跳；强调起跳力量和落地控制。


### 抱膝跳（Tuck Jump）

**标准动作描述：** 垂直起跳时主动抬膝接近胸部，落地后立即准备下一次；保持躯干控制，避免为了抬膝而塌腰。


### 跳箱（Box Jump）

**标准动作描述：** 从站立位摆臂起跳，双脚落在箱面并屈髋屈膝吸收冲击，再站直；箱高以动作稳定为准，不追求极限高度。


### 深度跳（Depth Jump）

**标准动作描述：** 从箱上走下落地，利用落地后的快速伸展反应立即起跳；必须先具备良好落地控制。


### 立定跳远（Broad Jump）

**标准动作描述：** 双脚屈髋屈膝预蹲，摆臂并向前跳远；双脚落地并主动吸收冲击。


### 跨步跳（Bounds）

**标准动作描述：** 以单腿交替向前跨跳，强调水平推进和髋部力量；每一步保持稳定落地与节奏。


### 滑冰者跳（Skater Jump）

**标准动作描述：** 从一侧单腿向另一侧跳，落在对侧腿上并稳定；保持髋膝踝对齐，控制横向摆动。


### 侧向跨跳（Lateral Bound）

**标准动作描述：** 单腿向侧方强力蹬地，跳到另一侧并单腿落地定住；逐渐增加距离。


### 高脚杯深蹲

**标准动作描述：** 双手在胸前托住壶铃/哑铃，脚站略宽于髋；髋膝同步屈曲下蹲，保持胸廓和足底稳定后站起。


### 前蹲

**标准动作描述：** 杠铃置于身体前侧肩部支撑位，肘部抬高；屈髋屈膝下蹲，保持躯干较直，再站起。


### 后蹲

**标准动作描述：** 杠铃置于上背部，双脚稳定；髋膝同步屈曲下蹲至目标深度，再通过脚底发力站起。


### 六角杠深蹲

**标准动作描述：** 站入六角杠中央，握把站起；以髋膝同步屈曲下蹲，再稳定站起，保持负荷位于身体两侧。


### 六角杠硬拉

**标准动作描述：** 站在六角杠中央，髋部后移并屈膝抓握；脚底发力伸髋伸膝站起，保持脊柱中立。


### 罗马尼亚硬拉（Romanian Deadlift, RDL）

**标准动作描述：** 双手持杠，从站立开始向后推髋，杠铃沿腿部下降；腘绳肌出现明显张力后，通过伸髋回到站立。


### 杠铃臀推（Barbell Hip Thrust）

**标准动作描述：** 上背部支撑在凳面，杠铃位于髋部；脚掌稳定，伸髋把骨盆抬至身体接近直线，再控制下降。


### 早安式（Good Morning）

**标准动作描述：** 杠铃置于上背部，膝盖微屈；向后推髋让躯干前倾，保持脊柱中立，再通过臀腿伸髋回正。


### 前向弓步（Forward Lunge）

**标准动作描述：** 向前迈步并下沉，前脚稳定承重，膝盖对准脚尖；推地回到站立。


### 分腿蹲（Split Squat）

**标准动作描述：** 前后分腿但双脚固定，垂直下沉并站起；前腿承担主要力量，保持骨盆稳定。


### 台阶上步（Step Up）

**标准动作描述：** 一脚完整踩上台阶，用台阶上的腿伸髋伸膝把身体带上去；避免过度借助后脚蹬地。


### 单腿箱式深蹲（Single-Leg Squat to Box）

**标准动作描述：** 单腿站立向后坐到箱/凳面，轻触后再单腿站起；控制膝盖和骨盆，不塌向一侧。


### 手枪深蹲（Pistol Squat）

**标准动作描述：** 单腿下蹲，同时另一腿前伸；保持支撑脚稳定和膝盖轨迹，达到可控深度后站起。


### 俯卧撑（Push-Up）

**标准动作描述：** 双手略宽于肩，身体保持一直线；屈肘降低胸部，再主动推地回到起始位。


### 哑铃卧推（Dumbbell Bench Press）

**标准动作描述：** 仰卧凳上，哑铃位于胸侧；控制下放，肘部适度外展，再向上推至接近伸直。


### 地雷管推举（Landmine Press）

**标准动作描述：** 一端固定杠铃，双手或单手握另一端；从肩前方向上前方推，保持躯干稳定。


### 反握引体向上（Chin-Up）

**标准动作描述：** 掌心朝向自己握杠，通过肩胛下沉和屈肘将身体拉起，再控制下降。


### 高位下拉（Lat Pulldown）

**标准动作描述：** 坐稳固定腿部，握住横杆向上胸方向下拉；保持胸廓稳定，不用身体后仰借力。


### 单臂哑铃划船（Dumbbell Row）

**标准动作描述：** 一手一膝或双脚稳定支撑，另一手持哑铃向髋部方向拉；肩胛受控移动，不耸肩。


### 坐姿绳索划船（Cable Row）

**标准动作描述：** 坐姿保持脊柱中立，向身体方向拉绳柄；肩胛向后收，再控制回程。


### 倒立划船（Inverted Row）

**标准动作描述：** 身体保持一直线，胸口向固定杠/把手靠近，再控制下降；根据杠高调整难度。


### 面拉（Face Pull）

**标准动作描述：** 绳索约脸部高度，双手向脸部拉并外旋，让手位于耳侧；保持肩胛控制。


### 弹力带肩外旋（Band External Rotation）

**标准动作描述：** 肘部贴近身体约90°屈曲，前臂向外旋转弹力带，再缓慢回位；避免耸肩。


### Y字抬臂（Y Raise）

**标准动作描述：** 俯卧或站立轻负荷，将双臂沿Y字方向抬起；重点是肩胛上回旋和下斜方肌控制。


### 肩胛俯卧撑（Scapular Push-Up）

**标准动作描述：** 保持肘基本伸直，只让肩胛骨前伸和后缩，身体随肩胛移动；不要把它做成普通俯卧撑。


### 死虫式（Dead Bug）

**标准动作描述：** 仰卧，腰背保持受控贴地；对侧手脚缓慢伸展，再回到中间，左右交替。


### 空心身体保持（Hollow Body Hold）

**标准动作描述：** 仰卧抬起肩胛和腿，腹部收紧，使身体形成轻微弧形；根据能力调整腿高。


### 平板支撑（Plank）

**标准动作描述：** 前臂或双手支撑，身体从头到脚跟保持直线；主动收腹、夹臀，避免塌腰。


### 腹轮滚动（Ab Wheel Rollout）

**标准动作描述：** 跪姿握腹轮，收紧腹部，髋肩同步向前伸展至可控范围，再利用核心拉回；不要让腰椎塌陷。


### 帕洛夫抗旋推（Pallof Press）

**标准动作描述：** 侧身站在绳索/弹力带固定点旁，双手从胸前推出并保持躯干不被拉向侧面，再收回。


### 单侧负重行走（Suitcase Carry）

**标准动作描述：** 单手持重物行走，另一侧不负重；保持躯干垂直、骨盆水平，不向负重侧倾斜。


### 农夫走（Farmer Carry）

**标准动作描述：** 双手各持重物行走，保持胸廓和骨盆稳定，步幅自然。


### 悬垂提膝（Hanging Knee Raise）

**标准动作描述：** 悬垂稳定后收紧核心，将膝盖向胸部方向抬起，再控制下放，避免大幅摆动。


### 悬垂举腿（Hanging Leg Raise）

**标准动作描述：** 悬垂后保持躯干稳定，主动屈髋将双腿抬高，再控制下降。


### 绳索砍劈（Cable Chop）

**标准动作描述：** 站立握绳索，从高位向对侧髋部斜向拉动；骨盆和胸廓协调旋转，保持核心控制。


### 绳索上提（Cable Lift）

**标准动作描述：** 从低位向对侧肩部斜向提拉绳索，保持脚底和骨盆稳定，让躯干产生受控旋转。


### 药球旋转投掷（Medicine Ball Rotational Throw）

**标准动作描述：** 侧身站立，髋部先旋转带动躯干和手臂，把药球向墙面或伙伴投出；重点是力量从下肢向上肢传递。


### 药球胸前传球（Medicine Ball Chest Pass）

**标准动作描述：** 双脚前后或平行站立，双手持球置于胸前；核心收紧，下肢稳定，双臂快速向前推出，同时转肩送胯将力量从下肢传递到上肢；球出手后手臂自然跟随，迅速准备下一次。重点体会全身力量传递，而非单纯手臂发力。


### 药球过顶砸地（Overhead Slam）

**标准动作描述：** 双手将药球举过头顶，利用躯干和髋部快速向下把球砸向地面，再安全拾回。


### 5米冲刺（5m Sprint）

**标准动作描述：** 采用适合自己的起跑姿势，前几步保持身体前倾并积极蹬地；目标是短距离快速加速。


### 前倾起跑（Falling Start）

**标准动作描述：** 身体整体前倾至即将失去平衡，再用前腿跨出进入冲刺；避免只从腰部折叠。


### 阻力冲刺（Resisted Sprint）

**标准动作描述：** 使用雪橇、弹力带等提供适度阻力，保持正常冲刺姿势；阻力不能大到破坏动作。


### 雪橇推（Sled Push）

**标准动作描述：** 双手握雪橇把手，身体前倾，连续有力地向后蹬地推进；保持躯干稳定。


### 飞行10米（Flying 10m）

**标准动作描述：** 先用逐渐加速区达到较高速度，再进入10米计时区；重点是最高速度阶段的放松和步频。


### A式小步跳（A-Skip）

**标准动作描述：** 交替抬膝并用对侧脚快速弹跳，保持躯干直立和脚踝弹性；用于跑姿节奏练习。


### B式小步跳（B-Skip）

**标准动作描述：** 在A式动作基础上将抬起的小腿向前下方主动伸展，再快速回收；保持节奏和控制。


### 5-10-5折返跑（5-10-5 Shuttle）

**标准动作描述：** 从中线起跑，先向一侧5码，再穿过中线跑10码到另一侧，最后返回起点；每次变向先降速再强力蹬地。


### T字折返测试（T-Test）

**标准动作描述：** 向前冲刺到中点，横向滑到一侧，再横向到另一侧，返回中点后后退回起点；按规定路线完成。


### 防守滑步（Defensive Slide）

**标准动作描述：** 低重心、胸口朝前，横向移动时保持双脚不交叉；脚步快速，膝盖对准脚尖。


### 侧向滑步（Lateral Shuffle）

**标准动作描述：** 运动方向侧向移动，双脚连续快速调整；保持髋膝微屈和躯干稳定。


### 卡里奥卡交叉步（Carioca）

**标准动作描述：** 身体侧向移动，前后交替交叉脚步，同时保持躯干朝向前方；从慢速开始建立协调性。


### 防守接近（Closeout）

**标准动作描述：** 从防守协防位置快速接近持球人，最后几步降低重心并碎步减速，保持可继续滑步的姿势。


### 原地大力运球（Pound Dribble）

**标准动作描述：** 保持低重心，用手指和手掌主动向下压球，球反弹至腰部以下；左右手交替。


### 胯下运球（Between-the-Legs）

**标准动作描述：** 在双腿形成通道时将球从一手穿过双腿换到另一手；保持低重心和视野抬起。


### 背后运球（Behind-the-Back）

**标准动作描述：** 利用手腕和前臂把球从身体一侧送到背后另一侧，保持身体移动方向稳定。


### 高速运球（Speed Dribble）

**标准动作描述：** 在前进中用较大幅度、较快节奏运球，球落点位于身体前侧并略向前。


### 犹豫步运球（Hesitation Dribble）

**标准动作描述：** 高速运球中短暂降低身体和球速，制造节奏变化，再快速加速突破。


### 体前内外运球（In-and-Out）

**标准动作描述：** 同一只手控制球先向外假动作，再快速向内收回改变方向；保持身体和球同步。


### 后撤运球（Retreat Dribble）

**标准动作描述：** 突破过程中快速向后退步拉开距离，同时控制球后撤，为重新进攻创造空间。


### 接球即投（Catch-and-Shoot）

**标准动作描述：** 提前准备手型和脚步，接球同时完成脚步调整并快速出手；减少多余停顿。


### 1-2步投篮脚步（1-2 Step）

**标准动作描述：** 接球后先落一脚、再落另一脚形成1-2节奏，并在第二脚稳定后起跳投篮。


### 双脚跳步投篮（Hop）

**标准动作描述：** 接球或运球后双脚同时落地完成跳步，再快速起跳出手；注意身体平衡。


### 急停跳投（Pull-Up）

**标准动作描述：** 运球推进后通过减速和脚步急停垂直起跳，保持上身稳定完成投篮。


### 横移跳投（Side Step）

**标准动作描述：** 先向侧方移动制造空间，再快速建立稳定投篮脚步并起跳出手。


### 后撤步跳投（Step Back）

**标准动作描述：** 从进攻脚步中向后撤开空间，双脚稳定后起跳；控制身体后移幅度。


### 欧洲步（Euro Step）

**标准动作描述：** 持球突破后连续两步改变横向方向，第一步制造防守人偏移，第二步向另一侧终结。


### 抛投（Floater）

**标准动作描述：** 突破进入中距离区域后单手或双手柔和抛球，利用高弧线越过协防者。


### 对抗终结（Contact Finish）

**标准动作描述：** 在合理身体接触下保持核心和上肢稳定完成上篮/投篮；先从可控接触开始。


### 跳步急停（Jump Stop）

**标准动作描述：** 移动中双脚同时落地完成急停，屈髋屈膝吸收惯性并保持平衡。


### 跨步急停（Stride Stop）

**标准动作描述：** 通过一脚先落地、另一脚随后落地完成急停，控制重心并准备下一动作。


### 中枢脚转身（Pivot）

**标准动作描述：** 建立一只中枢脚后保持其支点不移动，用另一脚带动身体转向；遵守篮球走步规则。


### 刺探步（Jab Step）

**标准动作描述：** 一脚快速向防守者方向探出制造假动作，再迅速收回进入突破或投篮。


### 撕裂步（Rip Through）

**标准动作描述：** 接球后将球从防守者身侧低位快速扫过，同时迈步突破；保持球远离防守者。


### 下沉转身步（Drop Step）

**标准动作描述：** 背身或接近篮筐时，一脚向侧后方落地形成空间，再转髋完成突破或终结。


### 二区有氧（Zone 2）

**标准动作描述：** 保持可以持续较长时间的低到中等强度，呼吸加快但仍能进行简短交流；以个人心率/体感区间为准。


### 90/90呼吸（90/90 Breathing）

**标准动作描述：** 仰卧、髋膝约90°，缓慢吸气扩张下侧肋骨，长呼气并轻收腹；重复数个呼吸循环。


### 鳄鱼式呼吸（Crocodile Breathing）

**标准动作描述：** 俯卧额头支撑，缓慢吸气让腹部和下侧肋骨向地面扩张，再长呼气放松。


### 方框呼吸（Box Breathing）

**标准动作描述：** 按固定节奏完成吸气、停顿、呼气、停顿，例如各4秒；以舒适和不憋气为原则。

### 2. 对复合训练动作的统一描述方式

对于"冲刺→急停→变向""跳跃→落地→再次跳跃"这类复合动作，不建议只写一个动作名称。以后训练计划中统一写成：

**起始姿势 → 第一阶段 → 制动/稳定 → 第二阶段 → 完成标准**

例如：

**冲刺→急停→90°变向（Sprint → Stop → 90° Cut）**

1. 从准备姿势开始加速；
2. 达到规定距离后提前降低重心；
3. 通过多步减速吸收水平速度；
4. 支撑脚稳定后完成90°变向；
5. 重新加速；
6. 重点观察膝盖轨迹、躯干控制和变向后第一步。

### 3. 全身力量传递模块（O）动作标准描述

#### 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press）

**标准动作描述：** 前后分腿站立（推荐对侧负重：左腿在前→右手持哑铃），哑铃置于肩部高度；保持骨盆中立、核心抗旋转，单臂向上推起哑铃至手臂接近伸直，再控制下放。全程骨盆不被拉向负重侧。

**关键要点：** 前腿稳定 + 臀部激活 + 骨盆控制 + 抗旋转。

**篮球迁移：** 对抗状态下的传球、护球、终结。

**退阶：** 半跪姿单臂哑铃推举 → 分腿姿无负重抗旋。

**进阶：** 分腿姿快速蹬伸单臂推举。

---

#### 分腿姿快速蹬伸单臂推举（Split-Stance Explosive Single-Arm Push Press）

**标准动作描述：** 低位分腿姿稳定，哑铃置于肩部；前腿快速蹬地、髋膝快速伸展，力量经核心传递至肩部，单臂爆发推起哑铃；落地时重新稳定在分腿姿。重点不是蹲多深，而是 Ground → Hip → Core → Upper 的力量链。

**关键要点：** 三关节伸展驱动推举，而非单纯手臂发力。

**训练意图：** Power（3–5 次/组，强调速度），非 Conditioning。

**退阶：** 弓步单臂哑铃推举 → 分腿姿 Push Press。

**进阶：** 动态/反应版本（接信号启动）。

**疼痛限制：** 膝部症状期不进入此动作，先完成分腿蹲和减速控制。

---

#### 哑铃火箭推（Dumbbell Thruster）

**标准动作描述：** 哑铃置于肩部，下蹲至舒适深度；快速站起完成踝膝髋三关节伸展，顺势将哑铃推过头顶；下放回肩位后进入下一次。

**训练意图：** 3–5 次 × 3–4 组偏 Power；12–15 次 × 多组偏 Conditioning/Work Capacity。同一动作需明确标注训练意图。

**退阶：** 高脚杯深蹲 + 哑铃肩推分开做。

**进阶：** 单臂火箭推、火箭推接跳跃。

---

#### 壶铃摆动（Kettlebell Swing）

**标准动作描述：** 双脚略宽于肩，壶铃置于体前地面；屈髋后推、腘绳肌加载，双手将壶铃后摆至双腿之间；快速伸髋伸膝，让壶铃自然摆至胸肩高度，再控制回程。动力来自臀和髋，不是用肩把壶铃抬起来。

**关键要点：** Hip Hinge 模式；顶点身体成一直线，不过度后仰。

**动作链定位：** RDL（建立髋伸力量）→ 壶铃摆动（快速髋伸）→ 立定跳远（水平爆发）→ 冲刺（专项输出）。

**退阶：** 罗马尼亚硬拉、壶铃 Deadlift。

**进阶：** 单臂摆动 → 哑铃高拉。

---

#### 哑铃高拉（Dumbbell High Pull）

**标准动作描述：** 站姿双手持哑铃于体前或体侧；屈髋加载后快速伸髋伸膝，顺势耸肩提肘将哑铃拉至胸肩高度，再控制下放。**不用考虑 Catch**，专注于快速伸髋。

**关键要点：** 肘部高于手腕；力量源自下肢而非手臂。

**进阶定位：** 壶铃摆动 → **哑铃高拉** → 悬垂哑铃高翻。

**退阶：** 壶铃摆动。

**进阶：** 悬垂哑铃高翻。

---

#### 悬垂哑铃高翻（Hang Dumbbell Clean）

**标准动作描述：** 哑铃置于膝上/大腿中段悬垂位；屈髋加载后快速伸髋伸膝耸肩，哑铃沿身体上升至肩部高度时快速转肘"接住"哑铃于肩部，再站直。技术门槛低于从地面启动的完整高翻，建议作为入门。

**退阶：** 哑铃高拉。

**进阶：** 哑铃高翻（地面启动）→ 单臂哑铃抓举。

---

#### 哑铃高翻（Dumbbell Clean）

**标准动作描述：** 哑铃从地面启动，通过快速伸髋伸膝将哑铃沿身体拉上，在肩部高度转肘接住，同时屈髋屈膝吸收，再站直。属于 Loaded Explosive Movement，补齐自重跳跃（CMJ/Box Jump/Broad Jump）之外的负重爆发体系。

**退阶：** 悬垂哑铃高翻。

**进阶：** 单臂哑铃抓举。

---

#### 单臂哑铃抓举（Single-Arm Dumbbell Snatch）

**标准动作描述：** 单手持哑铃于体前地面或悬垂位；快速伸髋伸膝耸肩，哑铃沿身体直线上升至头顶，手臂伸直锁定，同时微屈髋膝吸收；再控制下放。是高拉→高翻之后最自然的进阶，强调快速伸髋+全身力量传递。

**退阶：** 哑铃高翻。

**进阶：**  heavier load / 接深蹲抓举。

---

#### 壶铃高翻推举（Kettlebell Clean & Press）

**标准动作描述：** 壶铃从地面或悬垂位高翻至前架位（贴靠前臂），稳定后推举过顶；下放回前架位再回地面。一次完成髋爆发+上肢推的完整力量链。

**退阶：** 壶铃高翻、单臂壶铃推举分开做。

---

#### 壶铃单臂摆动（Single-Arm KB Swing）

**标准动作描述：** 与双手壶铃摆动相同模式，但单手持铃；身体会产生旋转力矩，需要核心抗旋转保持稳定。

**退阶：** 双手壶铃摆动。

**进阶：** 摆动接高翻。

---

#### 俯卧撑位交替哑铃划船（Renegade Row）

**标准动作描述：** 俯卧撑位，双手各握哑铃支撑地面，双脚略宽于肩；保持骨盆不旋转，单手将哑铃拉向髋部，再控制放下换侧。真正训练重点不是"背"，而是划船时身体想旋转、你的任务是不让它旋转。

**关键要点：** 划船 + 抗旋转核心 + 肩胛稳定 + 髋稳定。

**使用建议：** 放在 Upper Day / Core Slot，不作为主力背部增肌动作。

**退阶：** 高位支撑 Renegade Row（手撑凳面）、窄距俯卧撑位保持。

**进阶：** 增加负重、放慢离心、加俯卧撑。

---

#### V字坐姿单臂哑铃推举（V-Sit Single-Arm DB Press）

**标准动作描述：** 坐姿抬起双腿保持 V 字平衡，单手持哑铃于肩部；保持躯干稳定，单臂向上推起哑铃再控制下放。核心要求高，肩部推举易因稳定不足而变形。

**定位：** 辅助核心挑战动作，不替代 Landmine Press / Split-Stance Press / Pallof Press / Renegade Row。

**退阶条件：** 腰椎开始明显弓起时应降级（改为脚踩地或半躺姿）。

---

#### 前架单侧行走（Single-Arm Front Rack Carry）

**标准动作描述：** 单手持壶铃/哑铃于前架位（贴靠前臂、肘部收紧），保持躯干直立行走；核心抗侧屈+抗旋转，肩胛保持稳定。

**退阶：** 单侧负重行走。

**进阶：** 单臂过顶行走。

---

#### 单臂过顶行走（Overhead Carry）

**标准动作描述：** 单臂将哑铃/壶铃举过头顶锁定，肩胛主动稳定；保持躯干直立、肋骨不外翻行走。

**退阶：** 前架单侧行走。

---

#### 地雷管旋转（Landmine Rotation）

**标准动作描述：** 杠铃一端固定，双手握另一端于胸前；保持髋部朝向固定（或小幅旋转），通过躯干旋转将杠铃从一侧摆到另一侧，核心控制旋转速度。可先严格锁髋练纯躯干旋转，进阶允许髋部参与练全身旋转力量。

**退阶：** 绳索抗旋转保持。

**进阶：** 分腿姿地雷管旋转、动态跨步旋转。

---

#### 药球跨步旋转抛（Step-Behind Rotational Throw）

**标准动作描述：** 侧对墙站立，远离墙的一侧脚向后跨步（Step-Behind）；蹬地→髋旋转→躯干旋转→肩→手，将药球全力抛向墙面。完整呈现篮球运动力量链。

**退阶：** 原地药球旋转抛。

**进阶：** 单腿旋转抛。

---

#### 单腿旋转抛（Single-Leg Rotational Throw）

**标准动作描述：** 单腿站立或单腿支撑姿态下完成旋转抛球，同时考验单腿稳定与旋转爆发。

**退阶：** 跨步旋转抛。

---

#### 药球侧向抛（Medicine Ball Scoop Toss）

**标准动作描述：** 侧对目标，双手持球于远离目标侧髋部；通过髋部快速旋转驱动躯干，将球从低位"铲"向目标，力量路径为髋→躯干→上肢。

**退阶：** 原地慢速旋转抛。

---

### 4. 动作关系链（Regression / Current / Progression）

动作库不是孤立动作的集合，而是有退阶和进阶路径的网络。AI 选动作时应沿链条工作：疼痛或疲劳时沿链条退阶，能力增长时沿链条进阶。

#### 髋爆发链

```text
罗马尼亚硬拉（RDL）
↓
壶铃摆动（Kettlebell Swing）
↓
哑铃高拉（Dumbbell High Pull）
↓
悬垂哑铃高翻（Hang DB Clean）
↓
哑铃高翻（Dumbbell Clean）
↓
单臂哑铃抓举（Single-Arm DB Snatch）
```

#### 核心抗旋转链

```text
帕洛夫抗旋推（Pallof Press）
↓
单侧负重行走（Suitcase Carry）
↓
俯卧撑位交替哑铃划船（Renegade Row）
↓
分腿姿单臂推举（Split-Stance Single-Arm Press）
↓
分腿姿快速蹬伸单臂推举（Split-Stance Explosive Push Press）
```

#### 跳跃链

```text
快速下落定住（Snap Down）
↓
反向动作纵跳（CMJ）
↓
跳箱（Box Jump）
↓
落箱反应跳（Drop Jump）
↓
深度跳（Depth Jump）
↓
反应式跳跃（Reactive Jump）
```

#### 减速链

```text
台阶下蹲（Step Down）
↓
单脚落地
↓
前跳急停
↓
冲刺→急停（Sprint → Stop）
↓
冲刺→45°变向（Sprint → 45° Cut）
↓
反应式变向（Reactive COD）
```

#### 力量传递链（篮球专项）

```text
地雷管推举（Landmine Press）
↓
半跪姿单臂地雷管推举
↓
分腿姿地雷管推举
↓
弓步单臂哑铃推举
↓
分腿姿快速蹬伸单臂推举
↓
药球跨步旋转抛
↓
实战对抗终结
```

#### 应用示例

当输入"今天膝盖 3 分，昨天刚打完比赛"时，AI 沿跳跃链退阶：

```text
Depth Jump ❌ → Box Jump ❌ → CMJ △ → Snap Down ✓
甚至进一步：当天只做 Landing 技术 + Prehab
```

### 5. 扩展动作字段

动作库 2.1 起，每个动作建议包含以下字段，使 AI 能根据周期阶段 + 当天模块 + 能力短板 + Readiness + 疼痛自动选动作：

| 字段 | 说明 |
|---|---|
| 中文名（English Name） | 双标签便于检索 |
| 模块 | A–O 之一 |
| 能力标签 | 最大力量/单腿/爆发/抗旋转/力量传递… |
| 等级 L1–L4 | 当前运动员水平要求 |
| 动作模式 | Squat / Hinge / Lunge / Push / Pull / Rotate / Carry / Jump / Land |
| 单/双侧 | Bilateral / Unilateral / Alternating |
| 冲击等级 | 无/低/中/高（跳跃落地类重点标注） |
| 训练意图 | Strength / Power / Hypertrophy / Conditioning / Skill |
| 篮球迁移 | 对应场上场景（对抗终结/急停跳投/防守滑步…） |
| 退阶动作 | 沿动作关系链向上 |
| 进阶动作 | 沿动作关系链向下 |
| 疼痛限制 | 膝/踝/腰等部位症状期的使用规则 |
| 周期适用阶段 | 进入周/增量周/高刺激周/Deload 周 |
