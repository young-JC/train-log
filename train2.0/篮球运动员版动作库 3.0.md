# 🏀 篮球运动员版动作库 3.0

> 本版是在原《篮球运动员版动作库 2.0 / 2.1》基础上升级。
>
> 核心目标不是继续堆动作，而是让动作库成为 AI 推荐训练的结构化数据源：
>
> **周期阶段 → 当天训练槽位 → 能力短板 → 动作模式 → 动作等级 → 刺激预算 → 疼痛/恢复 → 进退阶链 → 最少必要动作。**

## 0. 3.0 使用原则

1. 所有名称统一使用 **中文名称（English Name）**。
2. “训练模块”与“能力标签”分开。
3. 每个动作同时描述：动作模式、主要/次要能力、L1–L4、机械冲击、神经要求、训练意图、周期阶段、推荐剂量、前置条件、进退阶、Quality Stop、疼痛限制。
4. AI 不因动作“高级”而优先推荐；必须匹配当前周期、当天槽位、恢复状态和刺激预算。
5. 同一训练日避免堆叠多个高度重复的动作模式，遵循 **最少必要动作（Minimum Effective Exercise Selection）**。
6. 速度、跳跃、减速、COD、负重爆发属于 **质量主导（Quality Dominant）** 项目；质量下降时提前结束。
7. 篮球实战视为“跳跃 + 冲刺 + 减速 + 变向 + 体能”的综合高强度暴露。
8. 疼痛限制优先于周期任务、弱点补强和 Readiness 总分。

| 字段 | 用途 |

## 0.2 刺激预算（Stimulus Budget）

| 刺激类型 | 代表内容 | 管理原则 |
|---|---|---|
| 低冲击 | Mobility、基础 Prehab、基础 Core | 可作为恢复/准备内容 |
| 中冲击 | Pogo、CMJ、Box Jump、基础减速 | 控制接触次数与质量 |
| 高冲击 | Depth Jump、高速 Sprint、高速 COD、Reactive Drill | 高质量低容量 |
| 高负荷力量 | Trap Bar、Squat、RDL、重 Bulgarian | 与高冲击下肢训练共同控制总量 |
| 篮球对抗 | 1v1、3v3、5v5 | 视为综合高强度下肢暴露 |

**原则：** 同一天通常只设置 1–2 个主要高质量目标。

## 0.3 Quality Stop 通用规则

出现任一情况时，结束该模块或退阶：

- 速度明显下降；
- 跳跃高度/距离明显下降；
- 落地声音明显变大；
- 膝内扣、骨盆或躯干控制明显恶化；
- 左右侧差异明显放大；
- 技术开始依赖代偿；
- 出现新的疼痛，或原有疼痛明显增加。

- 单脚快速下落定住（Snap Down） ⭐⭐

- 单脚跳 → 落地 ⭐⭐

```text
跳跃
↓
```

跳跃→定住→再次跳跃（Jump → Stick → Jump）

- 前进 → 急停 ⭐
- 后退 → 急停 ⭐⭐

#### D2 单腿制动

- 台阶下蹲（Step Down） ⭐⭐
- 单腿跳 → 停 ⭐⭐
- 单腿向前跳（Single-Leg Broad Jump） → 停 ⭐⭐
- 单腿侧向跳（Single-Leg Lateral Jump） → 停 ⭐⭐⭐

#### D3 高级

- 冲刺→急停（Sprint → Stop）
- 冲刺→后退跑（Sprint → Backpedal）

- 冲刺→45°变向（Sprint → 45° Cut）
- 冲刺→90°变向（Sprint → 90° Cut）
- 冲刺→180°转身（Sprint → 180° Turn）

### O. 全身力量传递（Kinetic Chain / Total-Body Power）

篮球不是"腿练腿、肩练肩"，而是：

```text
地面 → 脚 → 踝 → 膝 → 髋 → 核心 → 肩 → 手
```

这一模块专门训练**下肢→核心→上肢的力量传递**，是篮球对抗、起跳、传球和终结的底层能力。

#### O1 分腿姿上肢爆发（Split-Stance Upper Power）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press） | L2 | 分腿稳定、抗旋转、上下肢力量传递 |
| 分腿姿快速蹬伸单臂推举（Split-Stance Explosive Single-Arm Push Press） | L3 | 地面反作用力→髋→核心→肩→手的爆发链 |
| 分腿姿地雷管推举（Split-Stance Landmine Press） | L2 | 力量传递 + 肩胛稳定 |
| 半跪姿单臂地雷管推举（Half-Kneeling Landmine Press） | L2 | 髋稳定 + 核心抗旋转 + 肩推 |

**推荐做对侧负重**：左腿在前 → 右手持哑铃，产生旋转力矩迫使核心抗旋转。

#### O2 负重爆发（Loaded Explosive Movement）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 壶铃摆动（Kettlebell Swing） | L2 | 髋主导爆发、后链力量 |
| 哑铃高拉（Dumbbell High Pull） | L2–L3 | 快速伸髋、力量传递（无需 Catch） |
| 悬垂哑铃高翻（Hang Dumbbell Clean） | L3 | 快速伸髋 + RFD + 协调 |
| 哑铃高翻（Dumbbell Clean） | L3 | 全身负重爆发 |
| 单臂哑铃抓举（Single-Arm Dumbbell Snatch） | L3–L4 | 全身爆发最高阶 |
| 壶铃高翻（Kettlebell Clean） | L3 | 髋爆发 |
| 壶铃高翻推举（Kettlebell Clean & Press） | L3 | 全身力量链 |
| 壶铃单臂摆动（Single-Arm KB Swing） | L2–L3 | 髋爆发 + 抗旋转 |
| 哑铃火箭推（Dumbbell Thruster） | L2 | 蹲→伸髋伸膝→推举；低次数偏 Power，高次数偏 Conditioning |

**进阶链**：壶铃摆动 → 哑铃高拉 → 悬垂哑铃高翻 → 哑铃高翻 → 单臂哑铃抓举

#### O3 抗旋转复合（Anti-Rotation Complex）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 俯卧撑位交替哑铃划船（Renegade Row） | L2 | 划船 + 抗旋转核心 + 肩胛稳定 + 髋稳定 |
| V字坐姿单臂哑铃推举（V-Sit Single-Arm DB Press） | L2–L3 | 核心稳定 + 推举（优先级低于 Renegade Row） |

#### O4 药球爆发体系（Medicine Ball Power）

药球比复杂哑铃动作更值得增加——可以做到真正的"加速→释放"，而哑铃最终还得减速把重量停下来。

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 药球胸前传（Medicine Ball Chest Pass） | L1 | 基础水平爆发 |
| 药球过顶砸地（Medicine Ball Slam） | L1 | 垂直爆发 + 三关节伸展 |
| 药球旋转砸墙（Rotational Medicine Ball Throw） | L2 | 旋转爆发 |
| 药球侧向抛（Medicine Ball Scoop Toss） | L2 | 髋→躯干力量传递 |
| 药球跨步旋转抛（Step-Behind Rotational Throw） | L3 | 动态力量传递：跨步→蹬地→髋旋转→躯干→肩→手 |
| 单腿旋转抛（Single-Leg Rotational Throw） | L3–L4 | 单腿稳定 + 旋转爆发 |

#### O5 负重行走（Carry Series）

## 二十、给动作增加一个真正有用的"等级体系"

不要仅仅用：

⭐ / ⭐⭐ / ⭐⭐⭐

建议改成：

**L1 基础**

能够：

> 正确完成动作

**L2 运动员基础**

能够：

> 在负重、速度或者单腿情况下稳定完成

**L3 运动表现**

能够：

> 在高速、爆发、复杂环境下完成

**L4 篮球专项**

能够：

> 在反应、对抗、疲劳条件下完成

例如：

**深蹲**

```text
L1 高脚杯深蹲
↓
L2 六角杠深蹲
↓
L3 重负荷深蹲
↓
L4 深蹲 → 跳跃 → 冲刺
```

再比如：

**侧向能力**

```text
L1 侧弓步
↓
L2 滑冰者跳（Skater Jump）
↓
L3 侧向跨跳（Lateral Bound）
↓
L4 侧向跨跳（Lateral Bound） → Sprint → 防守接近（Closeout）
```

这才是真正的"运动员进阶"。

### 2. 对复合训练动作的统一描述方式

对于"冲刺→急停→变向""跳跃→落地→再次跳跃"这类复合动作，不建议只写一个动作名称。以后训练计划中统一写成：

**起始姿势 → 第一阶段 → 制动/稳定 → 第二阶段 → 完成标准**

例如：

**冲刺→急停→90°变向（Sprint → Stop → 90° Cut）**

1. 从准备姿势开始加速；
2. 达到规定距离后提前降低重心；
3. 通过多步减速吸收水平速度；
4. 支撑脚稳定后完成90°变向；
5. 重新加速；
6. 重点观察膝盖轨迹、躯干控制和变向后第一步。

### 4. 动作关系链（Regression / Current / Progression）

动作库不是孤立动作的集合，而是有退阶和进阶路径的网络。AI 选动作时应沿链条工作：疼痛或疲劳时沿链条退阶，能力增长时沿链条进阶。

#### 髋爆发链

```text
罗马尼亚硬拉（RDL）
↓
壶铃摆动（Kettlebell Swing）
↓
哑铃高拉（Dumbbell High Pull）
↓
悬垂哑铃高翻（Hang DB Clean）
↓
哑铃高翻（Dumbbell Clean）
↓
单臂哑铃抓举（Single-Arm DB Snatch）
```

#### 核心抗旋转链

```text
帕洛夫抗旋推（Pallof Press）
↓
单侧负重行走（Suitcase Carry）
↓
俯卧撑位交替哑铃划船（Renegade Row）
↓
分腿姿单臂推举（Split-Stance Single-Arm Press）
↓
分腿姿快速蹬伸单臂推举（Split-Stance Explosive Push Press）
```

#### 跳跃链

```text
快速下落定住（Snap Down）
↓
反向动作纵跳（CMJ）
↓
跳箱（Box Jump）
↓
落箱反应跳（Drop Jump）
↓
深度跳（Depth Jump）
↓
反应式跳跃（Reactive Jump）
```

#### 减速链

```text
台阶下蹲（Step Down）
↓
单脚落地
↓
前跳急停
↓
冲刺→急停（Sprint → Stop）
↓
冲刺→45°变向（Sprint → 45° Cut）
↓
反应式变向（Reactive COD）
```

#### 力量传递链（篮球专项）

```text
地雷管推举（Landmine Press）
↓
半跪姿单臂地雷管推举
↓
分腿姿地雷管推举
↓
弓步单臂哑铃推举
↓
分腿姿快速蹬伸单臂推举
↓
药球跨步旋转抛
↓
实战对抗终结
```

#### 应用示例

当输入"今天膝盖 3 分，昨天刚打完比赛"时，AI 沿跳跃链退阶：

```text
Depth Jump ❌ → Box Jump ❌ → CMJ △ → Snap Down ✓
甚至进一步：当天只做 Landing 技术 + Prehab
```
