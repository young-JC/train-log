## 维护规则

- 日期使用 `YYYY-MM-DD`，时间使用用户时区的 `HH:mm`（本项目默认 Asia/Shanghai）。未明确测量日期且无法从语境确定时只补问日期；时间可省略。补录旧测量时保留原测量日期，更新时间使用实际维护日期。
- 每条测量使用稳定且唯一的 ID：`BM-YYYYMMDD-NN`，同日序号从 01 起。至少一个指标有有效数值；身高、体重、腰围为正数，体脂率大于 0 且小于 100。异常输入请用户澄清，不擅自截断、换算口径或补测。
- 单位明确时可以换算为表头单位，保留原单位说明；单位不明确时补问。方法或设备按指标分别保存，用户只说明体脂秤测体脂时不擅自给其他指标补设备。
- 新测量追加历史，不覆盖旧测量。同一天不同时间或不同设备可分别保留；只有用户明确为同一次测量的补充时，才补充已有记录的缺失字段。
- 重复提交同一次测量及相同数据不追加、不刷新更新时间。多条记录无法判断属于哪次测量时，只询问时间、设备或记录 ID，不自动合并。
- 明确纠错按原 ID 原位修正，并在下表保留原值、修正值与原因；目标记录不明确时先询问。记录的最新值和趋势从修正后的完整历史重新取值，不受“只保留更好结果”限制。
- 各指标分别取截至分析日的最新有效值，并展示各自测量日期、方法和来源；后补的更早测量不得覆盖较新的指标。同日缺少时间且有多条测量时按记录 ID 排序，并说明时间未记录。
- Dashboard 默认显示截至今天最近 12 周（含今天 84 天）的历史，可切换全部；最新指标卡始终取完整历史，不随筛选改变。
- 体脂率仅在明确为同方法、同设备且测量条件可比时讨论变化。方法不明或不同的方法不连线、不计算变化率、不生成改善结论；记录值本身仍可查看。其他指标的数值变化也不等于能力改善。
