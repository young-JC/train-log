我建议把它设计成：

**动作库 2.0 → 能力画像 → 12周大周期 → 4周中周期 → 周微周期 → 每日训练 → 训练/学习打卡 → 疼痛与疲劳监控 → 自动调整 → 周期复测**

你原来的方案已经确定了一个重要原则：**速度/爆发先于力量**，同一肌群高强度训练之间留恢复时间，防伤激活不能跳过。这个原则我会保留，但把它扩展成完整的周期化系统。

另外，2026 年 ACSM 最新阻力训练立场强调：力量、爆发力等训练应该根据目标和个人情况调整，力量训练常使用较高负荷，而功率训练强调中等负荷和快速向心动作；同时，个体化和持续执行比复杂技巧更重要。

## 一、先确定整个系统的层级

以后不要直接从"动作库"跳到"今天练什么"。

应该是：

```text
                     🏀 篮球运动员训练系统
                              │
                ┌─────────────┴─────────────┐
                ↓                           ↓
             能力评估                     疼痛/健康
                │                           │
                └─────────────┬─────────────┘
                              ↓
                        当前能力画像
                              ↓
                       12周大周期目标
                              ↓
                       4周中周期目标
                              ↓
                        每周训练重点
                              ↓
                       每日训练模块
                              ↓
                         动作库选动作
                              ↓
                      训练量/强度/RPE
                              ↓
                       训练后数据记录
                              ↓
                    疼痛/疲劳/恢复反馈
                              ↓
                         自动调整
                              │
                              └────→ 下一次训练
```

**核心思想：**

动作不是计划，动作只是完成计划的工具。

## 二、第一层：能力评估

第一次开始12周周期之前，先建立你的"运动员基线"。

| ① Mobility | 踝、髋、胸椎 |
| ② Strength | 双腿、单腿、上肢 |
| ③ Power | 垂直/水平/侧向爆发 |

| ⑤ Deceleration | 减速能力 |
| ⑥ Speed | 10m/20m速度 |
| ⑦ Agility | 变向+反应 |

再单独增加：

| 能力 | 测什么 |
| --- | --- |
| ⑨ Injury / Pain Status | — |

因为你现在存在**膝部疼痛**，所以这一项不是"附属指标"。

考虑到你目前有膝部不适，第一轮不建议为了测试成绩去做真正的1RM极限测试。

- 8次

### 上肢

记录：

- Push-up
- Pull-up

- DB Row

## 五、爆发力测试

### ① CMJ 垂直跳

3次。

记录：

- Best Jump
- Average Jump

如果有跳跃测试设备就更好；没有的话用固定高度目标/手机慢动作也可以作为个人趋势记录。

### ② Standing Broad Jump

3次。

记录最好成绩。

### ③ Lateral Bound

左右分别记录：

- 左：X cm
- 右：X cm

重点不仅看距离，更看：**能不能稳定落住**。

## 六、落地能力测试

不要直接做复杂深度跳。

先：

### Drop Landing

低高度。

评分：

| 评分 | 描述 |
| --- | --- |
| 0 | 无法稳定 |
| 1 | 能完成但明显失控 |
| 2 | 稳定 |

观察：

- 膝盖是否明显内扣
- 躯干是否摇晃
- 左右受力是否明显不同
- 能否稳定停住

## 十三、动作选择的"六层过滤器"

每天选动作时按照：

### 第1层：今天训练什么能力？

例如：

周一 = 下肢力量 + 垂直爆发

### 第2层：当前周期需要什么？

例如现在处于：**基础阶段**

那么不应该突然大量加入：

- Depth Jump
- 高强度Reactive COD
- 复杂反应训练

而应该：**打基础**。

### 第3层：当前能力短板是什么？

假设测试发现：

| 能力 | 评分 |
| --- | --- |
| 力量 | 7/10 |
| 爆发 | 5/10 |
| 单腿 | 4/10 |
| 减速 | 3/10 |

那么训练资源应该向 **单腿 + 减速 + 爆发** 倾斜。

而不是继续堆深蹲。

### 第4层：今天身体状态允许什么？

例如：

- 昨天打了2小时篮球
- 今天起床膝盖明显不舒服

那么：今天不能机械执行原计划。

### 第5层：动作难度

优先选择：**能稳定完成的最高一级**。

而不是：最难动作。

### 第6层：训练刺激不能重复堆叠

例如：

- Box Jump
- Broad Jump
- Lateral Bound
- Depth Jump
- Sprint

全部高质量 —— 这通常就已经过量了。

所以：一次训练选择 **1个主爆发动作 + 1个辅助爆发动作** 即可。

## 二十五、训练量怎么控制？

不要用："今天状态好，全部加。"

建立三个变量：

- **Volume** — 组 × 次数
- **Intensity** — 重量/速度/难度
- **Density** — 单位时间内完成多少

每次训练：最好只明显提高其中一个。

你原动作库也采用"加重、加次、加组、控速一次选择一种"的渐进逻辑，并建议同一动作持续6–8次训练后再考虑进阶。

| W3 | 3×6 | RPE 7–8 |

## 二十七、爆发动作怎么进阶？

不是：跳得累死。

而是：

| Level | 动作 |
| --- | --- |
| Level 1 | 原地跳 |
| Level 2 | CMJ |
| Level 3 | Box Jump |
| Level 4 | Depth Jump |
| Level 5 | Jump → Land → React |

爆发训练的评价指标：**速度和质量，而不是疲劳**。

ACSM 2026 对功率训练同样强调中等负荷和快速向心动作。

## 二十八、速度动作怎么进阶？

不要：20米冲刺 × 20组。

而是：

| 阶段 | 内容 |
| --- | --- |
| 1 | 10m |
| 2 | 15m |
| 3 | 20m |
| 4 | 10m Reactive |
| 5 | 10m + Stop |
| 6 | 10m + Cut |
| 7 | Reaction Sprint |

逐渐增加复杂度。

## 二十九、敏捷怎么进阶？

这是非常重要的：

```text
Level 1    预设路线
                ↓
Level 2    固定变向
                ↓
Level 3    随机方向
                ↓
Level 4    视觉反应
                ↓
Level 5    带球反应
                ↓
Level 6    防守/对抗
```

所以：**梯绳不能成为敏捷训练主体**。

它更像是：Coordination / Footwork。

真正的篮球敏捷必须加入：**减速 + 决策 + 反应**。

| --- | --- |
| Level 1 | 每天 |
| Level 2 | 训练前 |
| Level 3 | 每周2–3次 |

## 三十一、Green / Yellow / Red 系统

> 🟢 **Green**
>
> 训练前：0–2/10左右
>
> 训练后没有明显增加。
>
> 第二天恢复到基线。
>
> → 正常执行计划

> 🟡 **Yellow**
>
> 出现：
> - 明显比平时疼
> - 热身时间明显增加
> - 第二天更疼
> - 单腿控制明显下降
>
> → 降低20–30%训练量
>
> 并优先保留：力量 + 技术
>
> 减少：高冲击跳跃 + 高速变向 + 大量冲刺

> 🔴 **Red**
>
> 出现：
> - 明显尖锐疼痛
> - 肿胀
> - 卡住
> - 膝盖打软/不稳
> - 明显跛行
> - 症状持续加重
>
> → 不要继续通过训练测试它。
>
> 停止高冲击训练并进行运动医学/物理治疗评估。

这套规则是**训练管理规则**，不是医学诊断标准。

你原来的指南同样明确把动作定位为防伤训练而非诊断，并建议持续4–6周规范训练无改善时寻求运动医学/康复评估。

## 三十二、为什么防伤模块不能删？

因为篮球的防伤并不是："膝盖哪里疼，练哪里。"

更合理的是：

```text
踝 → 膝 → 髋 → 核心 → 落地 → 减速 → 变向
```

篮球运动员的神经肌肉热身已经有研究支持其用于降低下肢伤病风险；篮球相关研究中，多成分热身通常结合跑动、力量、平衡、敏捷、跳跃等内容。

因此你的：**Prehab → Landing → Deceleration** 应该视为一个连续系统，而不是三个孤立模块。

## 三十四、训练调整规则

#### 状态 A

- 睡眠正常
- 疲劳低
- 疼痛稳定

→ 100%计划

#### 状态 B

- 轻微疲劳
- 轻微疼痛

→ 80–90%计划

#### 状态 C

- 明显疲劳
- 疼痛增加

→ 60–70%

删除：高强度Plyo / 高速COD

#### 状态 D

- 明显疼痛
- 明显疲劳
- 动作质量下降

→ Recovery / Prehab

## 三十五、训练负荷也要记录

每天训练结束记录：

- 训练时间：90分钟
- 主观强度：RPE 7

Training Load = 90 × 7 = 630

这个数字主要用来观察自己的趋势，不是一个医学阈值。

例如：

| 周 | Training Load |
| --- | --- |
| Week 1 | 1800 |
| Week 2 | 2050 |
| Week 3 | 2300 |
| Week 4 | 1500 |

就可以看到：Week 3是高负荷周，然后Week 4主动下降。

相比突然 1800 → 2500 → 3200 → 3500，更容易管理恢复。

加载与回归运动的核心确实需要控制"足够刺激"和"可恢复负荷"之间的平衡，但急慢负荷比例之类指标并不能单独作为康复/回归运动的决定依据。

### 最关键的设计原则

你以后制定任何训练计划，都只遵守这 **8条规则**：

1. ① 先定能力，再选动作。
2. ② 先定训练日目标，再填动作槽位。
3. ③ 爆发、速度、反应永远优先于力量训练。
4. ④ 每次训练不追求把动作库里的动作做遍，只选择完成当天目标所需的最少动作。
5. ⑤ 一个动作每次只改变一个主要进阶变量。
6. ⑥ 高强度下肢训练之间留足恢复，篮球实战本身也算高负荷下肢训练。
7. ⑦ Prehab不是"康复附加项"，而是训练结构的一部分。
8. ⑧ 疼痛、疲劳和训练表现可以修改当天计划，但不能让当天情绪决定训练计划。

这样，你的"动作库 2.0"就不再是一份100多个动作的列表，而会变成一个**有能力评估、有周期、有动作选择规则、有负荷控制、有疼痛反馈的训练系统**。

而且你目前的膝部方案其实已经有一个很好的基础：Level 1 每日、Level 2 训前、Level 3 每周2–3次，这个结构可以直接作为整个系统的 Prehab 层。
