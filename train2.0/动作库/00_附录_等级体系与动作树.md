## 二十、给动作增加一个真正有用的"等级体系"

不要仅仅用：

⭐ / ⭐⭐ / ⭐⭐⭐

建议改成：

**L1 基础**

能够：

> 正确完成动作

**L2 运动员基础**

能够：

> 在负重、速度或者单腿情况下稳定完成

**L3 运动表现**

能够：

> 在高速、爆发、复杂环境下完成

**L4 篮球专项**

能够：

> 在反应、对抗、疲劳条件下完成

例如：

**深蹲**

```text
L1 高脚杯深蹲
↓
L2 六角杠深蹲
↓
L3 重负荷深蹲
↓
L4 深蹲 → 跳跃 → 冲刺
```

再比如：

**侧向能力**

```text
L1 侧弓步
↓
L2 滑冰者跳（Skater Jump）
↓
L3 侧向跨跳（Lateral Bound）
↓
L4 侧向跨跳（Lateral Bound） → Sprint → 防守接近（Closeout）
```

这才是真正的"运动员进阶"。

## 二十一、最重要：给每个动作增加"篮球能力标签"

以后你的动作库最好不是只有：

> 动作 / 组数 / 次数

而是：

| 动作 | 能力 |
|---|---|
| 深蹲 | 最大力量 |
| 罗马尼亚硬拉（Romanian Deadlift, RDL） | 髋力量 |
| 保加利亚分腿蹲 | 单腿力量 |
| Nordic | 腘绳肌 |
| Copenhagen | 内收肌 |
| 提踵 | 踝力量 |
| 踝弹跳（Pogo Jump） | 踝弹性 |
| 跳箱（Box Jump） | 垂直爆发 |
| 立定跳远（Broad Jump） | 水平爆发 |
| 侧向跨跳（Lateral Bound） | 横向爆发 |
| 下落落地（Drop Landing） | 落地 |
| 台阶下蹲（Step Down） | 减速 |
| Sprint | 加速 |
| 5-10-5折返跑（5-10-5 Shuttle） | 变向 |
| 防守接近（Closeout） | 防守专项 |
| Pull-up | 上肢拉力 |
| Pallof | 抗旋转 |
| Medicine Ball Throw | 力量传递 |

这样你未来制定计划的时候，可以直接按照：

> 本周期缺什么能力 → 从动作库选择动作

而不是随机选动作。
