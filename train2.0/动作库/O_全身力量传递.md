## 模块说明


### O. 全身力量传递（Kinetic Chain / Total-Body Power）

篮球不是"腿练腿、肩练肩"，而是：

```text
地面 → 脚 → 踝 → 膝 → 髋 → 核心 → 肩 → 手
```

这一模块专门训练**下肢→核心→上肢的力量传递**，是篮球对抗、起跳、传球和终结的底层能力。

#### O1 分腿姿上肢爆发（Split-Stance Upper Power）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press） | L2 | 分腿稳定、抗旋转、上下肢力量传递 |
| 分腿姿快速蹬伸单臂推举（Split-Stance Explosive Single-Arm Push Press） | L3 | 地面反作用力→髋→核心→肩→手的爆发链 |
| 分腿姿地雷管推举（Split-Stance Landmine Press） | L2 | 力量传递 + 肩胛稳定 |
| 半跪姿单臂地雷管推举（Half-Kneeling Landmine Press） | L2 | 髋稳定 + 核心抗旋转 + 肩推 |

**推荐做对侧负重**：左腿在前 → 右手持哑铃，产生旋转力矩迫使核心抗旋转。

## 动作详情


### 2. 对复合训练动作的统一描述方式

对于"冲刺→急停→变向""跳跃→落地→再次跳跃"这类复合动作，不建议只写一个动作名称。以后训练计划中统一写成：

**起始姿势 → 第一阶段 → 制动/稳定 → 第二阶段 → 完成标准**

例如：

**冲刺→急停→90°变向（Sprint → Stop → 90° Cut）**

1. 从准备姿势开始加速；
2. 达到规定距离后提前降低重心；
3. 通过多步减速吸收水平速度；
4. 支撑脚稳定后完成90°变向；
5. 重新加速；
6. 重点观察膝盖轨迹、躯干控制和变向后第一步。

### 3. 全身力量传递模块（O）动作标准描述

#### 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press）

> **AI动作元数据**  
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）  
> - **动作模式：** 分腿姿垂直推 + 抗旋转  
> - **主要能力：** 力量传递 / 抗旋转  
> - **次要能力：** 核心稳定 / 协调  
> - **等级：** L2  
> - **机械冲击：** 中 ｜ **神经要求：** 高 ｜ **侧别：** 单侧  
> - **训练意图：** Loaded Power / Kinetic Chain  
> - **周期适用：** W1–W12；复杂负重爆发优先W5–W12  
> - **推荐剂量：** 3组 × 6–8次/侧  
> - **前置条件：** 能够无痛、稳定完成基础版本  
> - **退阶：** 半跪姿单臂推举  
> - **进阶：** 分腿姿快速蹬伸单臂推举  
> - **Quality Stop：** 速度下降、用上肢硬拉/硬推、接铃不稳或躯干代偿时停止  
> - **疼痛限制：** 存在膝/腰/肩明显症状时按动作链退阶  


**标准动作描述：** 前后分腿站立（推荐对侧负重：左腿在前→右手持哑铃），哑铃置于肩部高度；保持骨盆中立、核心抗旋转，单臂向上推起哑铃至手臂接近伸直，再控制下放。全程骨盆不被拉向负重侧。

**关键要点：** 前腿稳定 + 臀部激活 + 骨盆控制 + 抗旋转。

**篮球迁移：** 对抗状态下的传球、护球、终结。

**退阶：** 半跪姿单臂哑铃推举 → 分腿姿无负重抗旋。

**进阶：** 分腿姿快速蹬伸单臂推举。

**关键要点：** 三关节伸展驱动推举，而非单纯手臂发力。

**训练意图：** Power（3–5 次/组，强调速度），非 Conditioning。

**退阶：** 弓步单臂哑铃推举 → 分腿姿 Push Press。

**进阶：** 动态/反应版本（接信号启动）。

**疼痛限制：** 膝部症状期不进入此动作，先完成分腿蹲和减速控制。

**关键要点：** Hip Hinge 模式；顶点身体成一直线，不过度后仰。

**动作链定位：** RDL（建立髋伸力量）→ 壶铃摆动（快速髋伸）→ 立定跳远（水平爆发）→ 冲刺（专项输出）。

**退阶：** 罗马尼亚硬拉、壶铃 Deadlift。

**进阶：** 单臂摆动 → 哑铃高拉。

#### 杠铃跳耸（Barbell Jump Shrug）

> **AI动作元数据**
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）
> - **动作模式：** 髋铰链 / 三关节蹬伸 / 跳跃
> - **主要能力：** 快速伸髋 / 垂直功率
> - **次要能力：** 躯干控制 / 协调
> - **等级：** L3
> - **机械冲击：** 中–高 ｜ **神经要求：** 高 ｜ **侧别：** 双侧
> - **训练意图：** Power
> - **周期适用：** 优先W5–W12；W1–W4仅评估轻器械技术；减量周减组
> - **推荐剂量：** 首次2–3组×3次，熟练后3–4组×3–5次；组间2–3分钟；用可快速控制的轻负荷，不从深蹲或硬拉成绩换算重量
> - **前置条件：** 髋铰链与双脚落地稳定；有可靠握持、落地区域及教练技术反馈
> - **退阶：** 不跳的轻器械快速伸髋练习；或无负重深蹲跳
> - **进阶：** 保持同动作提高输出；需高拉技术时另学杠铃悬垂高拉
> - **Quality Stop：** 起跳输出下降、向前追杠、落地变响、手臂提前弯曲或需持续屏气时停止
> - **疼痛限制：** 膝、腰、肩或腕出现疼痛时停止相关变式；不以减轻重量强行完成疼痛动作。遵守个人明确负荷与呼吸限制。

**标准动作描述：** 双手以高翻握距持杠站立，后推髋使杠沿大腿降至膝上；快速蹬地伸髋伸膝并提踵，顺势耸肩、小幅离地，双臂保持伸直。落回原区域屈髋屈膝缓冲，重置后再做。

**关键要点：** 这是带跳跃的拉类衍生动作，不接杠；不要早屈肘或把耸肩当主要动力。

**器材：** 杠铃/训练杆

#### 杠铃翻拉（Barbell Clean Pull）

> **AI动作元数据**
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）
> - **动作模式：** 地面拉起 / 三关节蹬伸
> - **主要能力：** 下肢力量向快速拉起转化
> - **次要能力：** 躯干控制 / 协调
> - **等级：** L3
> - **机械冲击：** 中 ｜ **神经要求：** 高 ｜ **侧别：** 双侧
> - **训练意图：** Strength-Speed / Power
> - **周期适用：** 优先W5–W12；W1–W4仅评估轻器械技术；减量周减组
> - **推荐剂量：** 首次2–3组×3次；熟练后3–4组×2–4次，组间2–3分钟；先轻负荷，不采用超最大高翻负荷
> - **前置条件：** 地面起始位可维持中立脊柱；轻杆分段提拉路径稳定并有教练指导
> - **退阶：** 膝上轻器械蹬伸耸肩；地面起始受限则采用垫高起始位
> - **进阶：** 按目标维持翻拉；具备接杠条件时另学杠铃高翻

**标准动作描述：** 以高翻握距从地面起杠，先用腿推地使杠贴近小腿与大腿上行；杠过膝后协调快速伸髋伸膝提踵并耸肩。手臂保持伸直，不屈肘高拉、不翻肘接杠，受控回位。

#### 杠铃悬垂高翻（Barbell Hang Power Clean）

> **AI动作元数据**
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）
> - **动作模式：** 悬垂蹬伸 / 翻肘 / 浅蹲接杠
> - **主要能力：** 全身爆发 / 接杠协调
> - **次要能力：** 躯干控制 / 协调
> - **等级：** L3
> - **机械冲击：** 中–高 ｜ **神经要求：** 高 ｜ **侧别：** 双侧

> - **前置条件：** 髋铰链、快速蹬伸、前架位和浅蹲吸收均稳定无痛；已学习翻肘接杠与安全退出，有合格教练指导和适宜场地

#### 六角杠跳（Trap-Bar Jump）

> **AI动作元数据**
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）

> - **次要能力：** 躯干控制 / 协调
> - **等级：** L3
