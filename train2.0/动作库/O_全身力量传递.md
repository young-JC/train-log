## 模块说明


### O. 全身力量传递（Kinetic Chain / Total-Body Power）

篮球不是"腿练腿、肩练肩"，而是：

```text
地面 → 脚 → 踝 → 膝 → 髋 → 核心 → 肩 → 手
```

这一模块专门训练**下肢→核心→上肢的力量传递**，是篮球对抗、起跳、传球和终结的底层能力。

#### O1 分腿姿上肢爆发（Split-Stance Upper Power）

| 动作 | 难度 | 核心价值 |
|---|---|---|
| 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press） | L2 | 分腿稳定、抗旋转、上下肢力量传递 |
| 分腿姿快速蹬伸单臂推举（Split-Stance Explosive Single-Arm Push Press） | L3 | 地面反作用力→髋→核心→肩→手的爆发链 |
| 分腿姿地雷管推举（Split-Stance Landmine Press） | L2 | 力量传递 + 肩胛稳定 |
| 半跪姿单臂地雷管推举（Half-Kneeling Landmine Press） | L2 | 髋稳定 + 核心抗旋转 + 肩推 |

**推荐做对侧负重**：左腿在前 → 右手持哑铃，产生旋转力矩迫使核心抗旋转。

## 动作详情


### 2. 对复合训练动作的统一描述方式

对于"冲刺→急停→变向""跳跃→落地→再次跳跃"这类复合动作，不建议只写一个动作名称。以后训练计划中统一写成：

**起始姿势 → 第一阶段 → 制动/稳定 → 第二阶段 → 完成标准**

例如：

**冲刺→急停→90°变向（Sprint → Stop → 90° Cut）**

1. 从准备姿势开始加速；
2. 达到规定距离后提前降低重心；
3. 通过多步减速吸收水平速度；
4. 支撑脚稳定后完成90°变向；
5. 重新加速；
6. 重点观察膝盖轨迹、躯干控制和变向后第一步。

### 3. 全身力量传递模块（O）动作标准描述

#### 弓步单臂哑铃推举（Split-Stance Single-Arm DB Press）

> **AI动作元数据**  
> - **训练模块：** O｜全身力量传递（Kinetic Chain / Total-Body Power）  
> - **动作模式：** 分腿姿垂直推 + 抗旋转  
> - **主要能力：** 力量传递 / 抗旋转  
> - **次要能力：** 核心稳定 / 协调  
> - **等级：** L2  
> - **机械冲击：** 中 ｜ **神经要求：** 高 ｜ **侧别：** 单侧  
> - **训练意图：** Loaded Power / Kinetic Chain  
> - **周期适用：** W1–W12；复杂负重爆发优先W5–W12  
> - **推荐剂量：** 3组 × 6–8次/侧  
> - **前置条件：** 能够无痛、稳定完成基础版本  
> - **退阶：** 半跪姿单臂推举  
> - **进阶：** 分腿姿快速蹬伸单臂推举  
> - **Quality Stop：** 速度下降、用上肢硬拉/硬推、接铃不稳或躯干代偿时停止  
> - **疼痛限制：** 存在膝/腰/肩明显症状时按动作链退阶  


**标准动作描述：** 前后分腿站立（推荐对侧负重：左腿在前→右手持哑铃），哑铃置于肩部高度；保持骨盆中立、核心抗旋转，单臂向上推起哑铃至手臂接近伸直，再控制下放。全程骨盆不被拉向负重侧。

**关键要点：** 前腿稳定 + 臀部激活 + 骨盆控制 + 抗旋转。

**篮球迁移：** 对抗状态下的传球、护球、终结。

**退阶：** 半跪姿单臂哑铃推举 → 分腿姿无负重抗旋。

**进阶：** 分腿姿快速蹬伸单臂推举。

**关键要点：** 三关节伸展驱动推举，而非单纯手臂发力。

**训练意图：** Power（3–5 次/组，强调速度），非 Conditioning。

**退阶：** 弓步单臂哑铃推举 → 分腿姿 Push Press。

**进阶：** 动态/反应版本（接信号启动）。

**疼痛限制：** 膝部症状期不进入此动作，先完成分腿蹲和减速控制。

**关键要点：** Hip Hinge 模式；顶点身体成一直线，不过度后仰。

**动作链定位：** RDL（建立髋伸力量）→ 壶铃摆动（快速髋伸）→ 立定跳远（水平爆发）→ 冲刺（专项输出）。

**退阶：** 罗马尼亚硬拉、壶铃 Deadlift。

**进阶：** 单臂摆动 → 哑铃高拉。
