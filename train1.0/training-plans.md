# 训练计划框架 & 动作库

> 用于制定每周训练计划和选择训练动作
>
> 膝部防伤训练详见 [training-prehab.md](training-prehab.md)，每次训练前必须完成其中的 Level 2 激活。

---

## 一、训练日拆分逻辑

每次训练 = **热身（5-10min，含膝部防伤激活）→ 主项（爆发力/力量）→ 辅助项 → 核心 → 拉伸**

三条原则决定训练内容如何分配到各天：

1. **爆发力/速度敏捷第一优先** — 需要最高神经兴奋度，放在训练最前
2. **大重量力量训练不连续** — 同一肌群需要 48h+ 恢复
3. **篮球技巧可独立可结合** — 可作为独立技术日，也可放在力量/爆发力日后半段（低疲劳状态下优先）
4. **防伤训练不能跳过** — 每次训练前必须完成膝部激活（详见 [training-prehab.md](training-prehab.md) Level 2）

---

## 二、周计划模板

### 方案 A：3 练/周（推荐，与你当前节奏匹配）

| 日次 | 主项 | 结构 | 备注 |
|------|------|------|------|
| **Day 1** | 爆发力 + 下肢力量 + 核心 | 敏捷→爆发→深蹲主导→核心 | 强度最高的训练日 |
| **Day 2** | 上肢力量 + 核心 | 上肢推→上肢拉→核心 | 下肢休息，可穿插轻量有氧 |
| **Day 3** | 爆发力 + 篮球技巧 + 体能 | 爆发→运球/投篮→间歇/对抗 | 更偏向运动表现 |

### 方案 B：4 练/周（进阶后采用）

| 日次 | 主项 | 结构 |
|------|------|------|
| **Day 1** | 爆发力 + 下肢力量（深蹲主导） | 敏捷→爆发→深蹲→辅助→核心 |
| **Day 2** | 上肢力量（推拉均衡） | 上肢推→上肢拉→核心 |
| **Day 3** | 速度敏捷 + 篮球技巧 | 梯绳→变向→运球→投篮→实战 |
| **Day 4** | 爆发力 + 下肢力量（硬拉/单腿主导） + 体能 | 爆发→硬拉/弓步→间歇跑 |

## 四、动作为什么这样分类（选动作逻辑）

| 训练阶段 | 动作要求 | 组次范围 |
|---------|---------|---------|
| 激活/爆发力 | 多关节、快速、低疲劳 | 2-3组×5-8次 |
| 主项（力量） | 复合动作、大肌群 | 3-5组×5-10次 |
| 辅助项 | 单侧/辅助肌群 | 2-3组×8-15次 |
| 核心 | 控制优先、负重在后 | 2-3组×8-15次 |

动作库中的难度标记（⭐~⭐⭐⭐）帮你快速判断当前水平适合哪个选项：

- ⭐ **基础** — 新手友好，重点学动作模式
- ⭐⭐ **进阶** — 需要一定力量和稳定基础
- ⭐⭐⭐ **高级** — 对控制/爆发/协调要求高

## 五、渐进方式（如何加难度）

每次施训在同一动作上只选一种方式进阶：

```
加重  → 目标次数内完成即加（如 3×7 ×25kg → 3×7 ×27.5kg）
加次  → 同重量突破次数（如 3×7 → 3×8 → 3×10 再加重）
加组  → 同重量同次数加一组（如 3组 → 4组）
控速  → 慢离心/底部停顿（同重量更难，不做额外负荷）
```

**建议节奏**：同一个动作保持在 6-8 次训练再考虑进阶，不急于加重。

> **使用方式**：制定周计划时，从「二、周计划模板」选一个方案，再从「三、动作库」对应板块选动作填入每天的结构中。随着训练经验增加，逐渐在动作库中增加新动作。
