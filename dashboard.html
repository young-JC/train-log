🔥 L2 — 训前准备（每次训练前加入）
放在热身阶段，按训练日类型选 2-3 个。总用时控制在 5 分钟内。详见 training-prehab.md 拆分指南。
动作组次作用要点
弹力带侧走2x10步/方向臀中肌激活半蹲位，弹力带绑膝上，横向跨步保持高度不变，膝盖不内扣
站姿膝控2x10/腿膝周本体感觉单腿站立，另一腿屈膝抬至 90° 再缓慢伸至 30° 屈回，支撑腿膝盖不晃
腘绳肌拉长激活2x8/腿腘绳肌离心控制一脚前滑踩地，支撑腿屈膝下蹲使腘绳肌拉长，再主动伸膝伸髋拉回
踝背屈活动度2x10/侧踝→膝联动膝靠墙，脚跟不离地，膝向前压
侧向跨步蹲2x8/侧内收肌+膝冠状面稳定宽站姿侧跨屈单膝下蹲，对侧腿伸直，推回起始位
展开查看动作详解

弹力带侧走：弹力带绑膝上 → 半蹲位臀后坐背直 → 侧跨步幅 20-30cm → 保持半蹲高度 → 跟步收回不并拢 → 方向走 10 步换边。膝盖内扣说明弹力带太重。

站姿膝控：单腿站支撑膝微屈 → 另一腿屈膝抬至 90° 脚尖勾起 → 缓慢伸小腿至 30-45° 保持 1s → 缓慢屈回。核心：支撑腿膝盖不晃、骨盆不歪。站不稳先扶墙。

腘绳肌拉长激活：一脚跟向前滑出踩地脚尖勾起 → 支撑腿屈膝下蹲，腘绳肌拉长 → 拉伸感明显时停 1s → 支撑腿主动伸膝伸髋推回，前脚收回。发力在大腿后侧。

踝背屈活动度：面对墙脚尖距 5-10cm → 膝靠墙脚跟不离地 → 碰到保持 2s 退回。轻松碰到就脚后移，碰不到往前移。

侧向跨步蹲：宽站姿 1.5-2 倍肩宽脚尖朝前 → 重心移向一侧屈膝下蹲髋后坐 → 对侧腿伸直脚踩实 → 大腿平行地面或内收肌有拉伸感 → 蹬地推回。躯干不弓背、膝不超脚尖。

训练日拆分逻辑 & 渐进方式

🐐 训练日结构
每次训练 = 热身（5-10min，含膝部防伤激活）
→ 主项（爆发力/力量）
→ 辅助项
→ 核心
→ 拉伸

四条原则：

  1. 爆发力/速度敏捷第一优先 — 需要最高神经兴奋度，放在训练最前
  2. 大重量力量训练不连续 — 同一肌群需要 48h+ 恢复
  3. 篮球技巧可独立可结合 — 可作为独立技术日，也可放在力量/爆发力日后半段（低疲劳状态下优先）
  4. 防伤训练不能跳过 — 每次训练前必须完成膝部激活（Level 2）
📈 渐进方式（如何加难度）
每次施训在同一动作上只选一种方式进阶：
加重 → 目标次数内完成即加（如 3x7 x25kg → 3x7 x27.5kg）
加次 → 同重量突破次数（如 3x7 → 3x8 → 3x10 再加重）
加组 → 同重量同次数加一组（如 3组 → 4组）
控速 → 慢离心/底部停顿（同重量更难，不做额外负荷）
建议节奏：同一个动作保持在 6-8 次训练再考虑进阶，不急于加重。
